# 中国三维地形

可在浏览器里平移、缩放、旋转的中国及周边国家三维地形模型，并可沿时间轴查看从战国（前 403 年）到今天的历代疆域、都城和古城。整个页面是一个 `index.html` 文件，地形数据已内嵌在里面，可以直接打开，也可以用 GitHub Pages 托管。

**在线访问：<https://laskfla.github.io/china-terrain-3d/>**（电脑和手机浏览器均可，无需安装）

> 本项目受 [DeanChensj](https://github.com/DeanChensj) 的 [jiangshan-map（江山时序）](https://github.com/DeanChensj/jiangshan-map) 启发而做：那是一部可沿时间轴浏览的二维中国历史地图集。这里把它的历代疆域、都城与古城数据搬到了三维地形上。

也可以直接打开某一年，例如 [唐 · 741 年](https://laskfla.github.io/china-terrain-3d/?year=741)、[北宋 · 1100 年](https://laskfla.github.io/china-terrain-3d/?year=1100)；只看今日地形用 [`?mode=modern`](https://laskfla.github.io/china-terrain-3d/?mode=modern)。

## 功能

- **历代疆域**（默认打开，右上角「历代疆域」按钮切换）
  - 时间轴覆盖战国至今 18 个时期、180 多个版图阶段：拖动滑块、点朝代色带跳到该朝，‹ › 逐阶段前后切换，▶ 自动播放。
  - 各政权的疆域着色并描边贴在地形上（主朝、对峙政权实线，都护府等羁縻地区虚线），标注政权名；左下角列出当前政权，点击可飞到该处。
  - 都城（红点）和当时的城市按年份显示，悬停或轻点可看古今地名与简介；悬停地面会显示所属政权和今属省份。
  - 历史水系随年份变化：黄河下游各时期河道（禹贡故道、王景故道、北宋北流与东流、夺淮故道、1855 年后今道与废黄河）、济水、古淮河与泗水；云梦泽、巨野泽／梁山泊、罗布泊在存在的年代显示为湖，洪泽湖（1194 年后）和微山湖（1560 年后）形成前显示为陆地。
  - 「地理变迁」注解：在海岸线、河湖、沙漠变化大的 17 处（如铜瓦厢决口、范公堤与苏北海岸、长江口成陆、珠江三角洲、黄河新三角洲、云梦泽、梁山泊、洪泽湖、罗布泊、楼兰、统万城、黄土高原）放置 ⓘ 标记，悬停或轻点查看说明；时间轴下方的「水系」一行说明当年黄河下游的走向。海岸线的变化目前只在注解中说明，地图上仍是今天的海岸。详见[历史时期的地理变化](#历史时期的地理变化)。
  - 1949 年以后显示今日省界与国界。地址栏的 `?year=` 会随时间轴更新，便于分享。
- **真实高程**：东经 60°–146°、北纬 3.5°–56°，0.1° 网格（约 9 公里），数据源自 NASA 全球地形图，经 40 多个已知海拔地点校准。
- **地图式操作**
  - 电脑：左键拖动平移，滚轮在指针处缩放，双击放大，右键或 Shift+拖动旋转，方向键平移。
  - 手机：单指平移，双指捏合缩放，双指拖动旋转。
- **近看加细节**：放大时，视野中心会生成约 1 公里的细分网格，海岸线和湖岸也会变得平滑。
- **标注**：地形区、山脉、山峰（含高度）、25 条河流、湖泊、海域、南海诸岛、省会和主要城市、邻国首都、国名。标注按缩放级别逐级出现，并自动避让重叠。
- **界线**：省界，以及国界（粉色底带加点划线，宽度按屏幕像素计算）。
- **其他**：可调垂直夸张倍数，点击或悬停查看所在省份/国家、经纬度和海拔；支持深色模式，手机竖屏可用。

## 直接使用

最简单的方式是打开在线页面 <https://laskfla.github.io/china-terrain-3d/>。也可以下载本仓库，双击 `index.html` 用浏览器打开。需要联网，因为 three.js 从 jsDelivr CDN 加载。

浏览器要求：Chrome / Edge 80+、Safari 16.4+、Firefox 113+（需要支持 WebGL 和 `DecompressionStream`）。

## 推送到 GitHub

```bash
cd china-terrain-3d
git init
git add .
git commit -m "中国三维地形"
git branch -M main
git remote add origin https://github.com/<你的用户名>/china-terrain-3d.git
git push -u origin main
```

如果要发布成网页：在仓库的 **Settings → Pages** 里，把 Source 设为从 `main` 分支的根目录部署。几分钟后就能通过 `https://<你的用户名>.github.io/china-terrain-3d/` 访问。

## 重新生成数据

一般不需要重新生成，`index.html` 已经是成品。只有修改了地形数据、河流或标注坐标时才需要。

依赖：Python 3.9+、Node.js 18+、git。

```bash
pip install -r requirements.txt
bash tools/fetch_sources.sh        # 下载源数据到 sources/（约 6 MB，git 稀疏克隆）
python3 tools/build_data.py        # 生成 build/terrain.json（高程、区域、起伏度、界线、河流）
node tools/build_history.js        # 生成 build/history.json（历代疆域、阶段、城市，取自 jiangshan-map）
python3 tools/build_page.py        # 把数据嵌入 src/template.html，输出 index.html
```

可选：离线截图检查。需要先 `npm i playwright && npx playwright install chromium`。

```bash
node tools/screenshot.js build/shots   # 输出全景、珠峰、四川盆地、手机，以及唐、北宋、明的截图（PNG）
```

构建结果是确定的：同样的输入，每次生成的 `index.html` 完全一样。

```

tools/geo_util.py           ECharts 压缩坐标解码
tools/screenshot.js         无头浏览器截图
docs/                       README 用的截图
```

## 历史时期的地理变化

本项目的所有时代都画在今天的地形上。这样做的依据，以及哪些变化在地图上画了、哪些只在注解里说明，记录如下。

### 基本没变的：山地与高原

青藏高原至今仍在抬升，但速度只有每年几毫米，两千多年累计不过几米；地震造成的地表错动也是米级、局部的（如 1556 年华县地震、2008 年汶川地震）。在约 9 公里的网格和 20 倍垂直夸张下，这些变化都看不出来，所以各时代沿用今天的高程是合理的。近两三千年海平面也大体稳定，变化在 1 米上下。

### 变化大的：河流

黄河下游是变化最剧烈的地方。泥沙主要来自黄土高原，下游河床不断淤高，于是"善淤、善决、善徙"。地图上按年份切换以下河道（取自 jiangshan-map 的示意走向），时间轴下方的「水系」一行同步说明：

| 年代 | 黄河下游走向 | 地图上 |
| --- | --- | --- |
| 公元 10 年以前 | 西汉以前的故道（"禹贡故道"），经今河北中部在天津一带入渤海 | 河水（禹贡故道） |
| 11 — 1047 年 | 公元 11 年改道，东汉王景治河（69 年）后走新道，在今山东利津一带入海，约八百年较为安定 | 黄河（王景故道） |
| 1048 — 1193 年 | 北宋时北流、东流并存，屡次决徙，大致在今天津与山东北部之间入海 | 黄河（北宋北流）及东流 |
| 1194 — 1854 年 | 南流夺淮：1128 年杜充决河、1194 年阳武决口后，经今苏北入黄海，淮河下游被占 | 黄河（夺淮故道） |
| 1855 年以后 | 铜瓦厢决口后北徙，走今道在山东入渤海；苏北留下废黄河 | 今黄河、废黄河 |

同时按年代显示的还有：济水（1855 年以前，北宋以后下游称大清河，1855 年被黄河夺占）、古淮河独流入海的下游与泗水（1194 年以前）。

### 变化大的：湖泊

| 湖泊 | 变化 | 地图上 |
| --- | --- | --- |
| 云梦泽 | 先秦至汉代江汉平原上的大片湖沼，魏晋南北朝时被长江、汉水泥沙淤积而解体，江汉平原由此形成 | 316 年以前显示为湖 |
| 洞庭湖 | 云梦泽消失后逐渐扩大，清代中后期最大（"八百里洞庭"）；近代淤积和围垦使其大大缩小 | 仅注解 |
| 巨野泽 → 梁山泊 | 鲁西南古湖；五代至北宋黄河决口注入后北移扩大为梁山泊，金元以后淤平，残留为今东平湖 | 1279 年以前显示为湖 |
| 洪泽湖 | 原为淮河边的小湖洼；黄河夺淮后淮河排水不畅，明代潘季驯大筑高家堰，众湖连成今湖，成为"悬湖" | 1194 年以前显示为陆地 |
| 南四湖（微山湖等） | 明代中后期黄河泛滥、运河改道后，在鲁南洼地积水而成 | 1560 年以前显示为陆地 |
| 罗布泊（蒲昌海） | 塔里木河、孔雀河下游多次改道，湖的位置和大小随之摆动；20 世纪上游大规模引水后，1970 年代初干涸 | 1971 年以前显示为湖 |
| 居延海 | 汉代水面广阔，汉军屯田（居延汉简）；黑河改道和上游用水使其萎缩，1990 年代一度干涸，2002 年起调水后部分恢复 | 仅注解 |

### 变化大的：海岸线（目前只在注解中说明）

这几处的古海岸位置缺少可以直接使用的数据，地图上仍画今天的海岸，变化写在「地理变迁」注解里：

- **苏北沿海**：北宋范仲淹修筑的捍海堰（范公堤）大致是当时的海岸。黄河夺淮的几百年间泥沙堆积，海岸向东推进了几十公里；1855 年黄河北徙后泥沙断供，废黄河口一带转为侵蚀后退。
- **长江口**：六七千年前的海岸约在今上海西部的"冈身"一带，此后海岸不断东移；今上海市区东部和浦东大部分是唐宋以后陆续成陆的，崇明岛由唐代出露的沙洲长大而成。
- **珠江三角洲**：唐宋时广州以南还是多岛的浅海湾，宋代以后泥沙淤积加上筑堤围垦沙田，三角洲迅速扩展。
- **渤海西岸**：天津平原上的几道贝壳堤是不同时期的古海岸遗迹，海岸随黄河、海河的泥沙向东推进。
- **黄河新三角洲**：1855 年以后在山东东营一带淤出大片新陆地；1976 年起黄河改由清水沟入海，河口仍在变化。

### 变化大的：沙漠、绿洲与水土流失（只在注解中说明）

- **塔里木盆地与楼兰**：塔克拉玛干沙漠形成于几百万年前，盆地在整个历史时期都是干旱区。楼兰在公元 4 世纪以后废弃，主要与孔雀河改道、水源断绝有关；变化的是河流和绿洲的位置，而不是整个地区由湿变干。
- **毛乌素沙地与统万城**：十六国时赫连勃勃所建的统万城（413 年起筑）当时周围有湖泊河流；唐代以后垦殖放牧使沙化加剧，北宋初（994 年）城被废弃，如今在沙地南缘。
- **黄土高原**：森林和草原不断被开垦，水土流失加剧，黄河泥沙增多——这正是黄河下游频繁改道的根本原因。

### 气候：有冷暖干湿的波动，但没有画成图层

据竺可桢等人的研究，东部季风区大致是秦汉、隋唐偏暖，东汉至南北朝、明清（小冰期）偏冷。新疆等西北干旱区受西风带控制，干湿变化常与东部相反，例如明清小冰期时中亚干旱区反而相对偏湿（陈发虎等）。这些波动缺少可靠的格网数据，画成图层容易误导，所以没有在地图上表现。

## 数据与精度说明

- **高程**：NASA 全球地形图（4096×2048，约 0.09°），按 `海拔 = 28.1 × (灰度 − 23.5)` 换算。在 44 个已知海拔的地点上，误差大多在 ±150 米以内。网格较粗，高峰会被平均掉，例如珠峰附近在模型中约 6500 米，标注里写的是真实高度。
- **近看细节**：比原始网格更细的起伏是按当地起伏度程序生成的，只是视觉示意，不是实测数据。
- **水体与海岸线**：来自 NASA 水体掩膜。
- **省界与国界**：来自 Apache ECharts 4.9 自带的中国地图和世界地图数据。中国国界取自中国地图的省级外轮廓；邻国之间的国界取自世界地图。
- **河流、地名坐标**：手工整理，属于近似位置。
- **历史河道与湖泊**：同样取自 jiangshan-map，河道为手绘示意走向，构建时做了平滑。山地和高原的高程在两千多年里变化很小（构造抬升每年只有毫米级），所以各时代都用今天的地形；变化较大的海岸线（苏北、长江口、珠江口、渤海西岸、黄河口）目前还没有按时代绘制。
- **历代疆域、都城与古城**：取自 [jiangshan-map](https://github.com/DeanChensj/jiangshan-map)（固定在提交 `b66b846`），为示意性复原，不是精确的历史边界。轮廓简化到约 1 公里精度；与本项目海岸线不吻合处，疆域着色会向外延伸约 10 公里补齐。

> 依据《地图管理条例》，在中国境内公开发布的地图需要送审并取得审图号。本项目仅供学习和演示，不应作为正式地图使用。
